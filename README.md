# שבילי מורשת — אתר ליווי

אתר סטטי ליחידת הלימוד **"ארץ ישראל: זיכרון, זהות ושייכות"** לכיתות ז'–ח', מונגשת לתלמידים עם לקויות למידה.

🧪 ממעבדת הניסויים של מרי גרבי

## מה יש כאן

- **5 מצגות** להקרנה בכיתה — נפתחות בדפדפן, עם הגדלת טקסט, ריווח לדיסלקציה וניגודיות גבוהה.
- **דפי עבודה בשלוש גרסאות** ("שבילים") — דף דו-צדדי אחד לכל שיעור, PDF להדפסה.
- **אזור מורה** — מדריך התאמות ונספח מערכי השיעור המלאים.
- **קישורים למערכים המקוריים** באתר משרד החינוך — תמיד הגרסה העדכנית.

## הפעלה מקומית

```bash
python3 -m http.server 8000
```

ואז לפתוח <http://localhost:8000>.

## בנייה מחדש

דפי האתר נוצרים מסקריפט. אחרי שינוי תוכן:

```bash
python3 build/site.py
```

## פרסום ב-GitHub Pages

1. `git init && git add -A && git commit -m "initial"`
2. ליצור רפו חדש בגיטהאב ולדחוף אליו.
3. **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
4. הקובץ `.nojekyll` כבר קיים ונדרש — אין למחוק אותו.

## לפני שעורכים

יש לקרוא את [`CLAUDE.md`](CLAUDE.md) — הוא מסביר אילו קבצים נוצרים אוטומטית ואילו מוסכמות אסור לשבור.

## רישוי ותכנים

התכנים החינוכיים הם של מחברת הערכה. מילות שירים, מפות וטקסטים ספרותיים מוגנים **אינם** כלולים במאגר — ראו את עמוד המקורות באתר.
